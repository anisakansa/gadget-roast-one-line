One original line roasting the gadget I use every day — my wireless earbuds, which wait until I'm mid-sentence on a call to fall out, then whisper "battery low" like they're gossiping about me. The joke is mine, written for this bounty, and the entry is the single line the program writes out.

## The bounty

[One-Line Roast: The Gadget You Use Every Day](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) — write one original line, at most 200 characters, roasting a gadget or app you use every day. Free to enter, $5 pot, top 3 paid.

## Run it

```sh
node main.ts
```

This writes the roast — exactly one line, 121 characters, no trailing newline — to `/output/entry.txt`. The program guards the gate itself: it refuses to write anything shorter than 1 character, longer than 200, or containing a newline.
